# 📂 有序星球 (Ordered Planet)

> **一个把“记账”做成生活小品、而不是财务报表的本地记账 Web App。**

---

## 🌟 项目简介

**「有序星球」** 是一款专为大学生及个人打造的轻量级记账单页应用（SPA）。
它没有冗杂的财务科目，没有烦人的社交和广告。它只专注于一件事：**让你通过极其舒适、好看的方式，记录下每一笔收支，并看清钱都花在了哪里。**

所有的数据都保存在本地，不需要登录，不经过任何服务器。

---

## ✨ 核心特性

### 📝 1. 极致顺滑的记账体验
*   **分账记账**：吃个饭想 AA？输入总金额和人数，自动帮你算出实记金额。
*   **快捷速记**：常用金额做成胶囊，单击展开、双击直接记账、长按拖拽排序。
*   **长按详情**：在明细页长按任意一条记录，即可弹窗查看包含流水号、精确到秒的时间等完整信息。
*   **丝滑动效**：删除记录时触发“碎片飘散”动画；弹窗从触发点弹性放大；Apple 式分段选择器滑动。

### 📊 2. 专业级数据统计
*   **多维度分析**：支持“支出 / 收入 / 净收入”三种口径，按月、按年自由切换。
*   **多图表展示**：条形图、环形图、按日柱状图、趋势折线图、按月对比图，全方位解析消费习惯。
*   **同环比分析**：自动与上期对比，涨跌趋势一目了然。
*   **预算与额度控制**：可设置月度总预算及分类单独限额，花超了会弹窗警告。

### 🎨 3. 卷到极致的视觉系统
*   **Pantone 流行色**：内置 20+ 套精心调配的年度流行色主题（如草木绿、长春花蓝、柔和桃等）。
*   **自定义壁纸**：上传你喜欢的图片作为背景，系统会自动提取图片的主色作为主题色。
*   **双料玻璃质感**：支持“毛玻璃（模糊）”和“透玻璃（亚克力）”两种高级质感，沉浸式顶栏与底部 Dock。
*   **动物岛风格**：内置一套 Q 弹 3D 像素风的 UI 皮肤，圆润的药丸按钮和游戏按键般的按压反馈。

### 🔮 4. 趣味与仪式感
*   **每日签到运势**：在首页顶部下拉，即可抽取今日运势（大学生专属定制版），带连续签到打卡。
*   **月度账单海报**：一键生成精美的月度财务报告长图，支持保存到相册分享。

### 🔒 5. 数据安全与备份
*   **纯净的导入/导出**：一键导出 JSON 格式备份。
*   **智能合并**：导入备份时，自动按 ID 去重；如果备份里包含本地没有的分类，会自动补建分类，**绝不篡改**你已有的历史记录。
